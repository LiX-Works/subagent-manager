# 自定义规则放在哪里

本仓库的 `skills/subagent-manager/` 只包含通用委派方法。具体模型优先级、推理档位最低值、账户预算、平台排除项、个人订阅策略，都由使用者根据自己的账户和任务决定。

若某条规则**需要代理实际执行**，应在自己的本地 Skill 或项目指引中明确写入并测试；仅放在本仓库 README 或本 `docs/` 下，不能保证模型每次看到，更不应把说明性文字冒充自动生效的配置。若只是分享经验、取舍理由或可选建议，放在仓库外层的 `docs/` 即可，不必写进公共 `SKILL.md`。

本公开版本保留一份[可选的模型档位写法示例](../skills/subagent-manager/references/native-models.md)，但它只有在当前用户明确采用时才生效。Google 优先、具体 Grok 预算阈值、账户状态和登录资料暂不收录，避免读者无意继承另一人的预算和偏好。
