# 使用前适配这份个人工作流

本仓库保留了作者实际使用的模型分工和 Grok 预算规则，因为它们展示了完整的决策过程；这些是**示例默认值**，不是 Codex 或 Grok 对所有账户的统一建议。只有当 Skill 被安装并选用时，其中的指令才可能影响代理行为；README 和本说明不自动改变你的配置。

建议先检查四件事：

1. **模型和档位**：核对当前 Codex 子代理工具是否暴露 Luna、Sol、Astra，以及能否在调用参数中同时显式指定模型和思考强度。[模型规则](../skills/subagent-manager/references/native-models.md)中的选档、旧模型下限、Astra Low 默认不用等是本案例的偏好，可按自己的成本、质量和工具支持情况修改。不可用时不要静默继承主代理设置。
2. **外部 CLI**：AGY 和 Grok 都不是必装。独立 CLI 不会自动继承 Codex 中已有的 Skill、MCP 或搜索入口；若安装，应自行登录、核对当前 help／模型列表，并先用小任务验收。不要把命令示例当作任何账户已获授权或享有相同套餐额度的证明。
3. **Grok 预算**：[预算规则](../skills/subagent-manager/references/grok-budget.md)使用 Asia/Shanghai 自然日和 1/7、1.5/7、2/7 三个个人阈值。其他时区或预算偏好需要同时改说明与账本脚本；显示的整数百分比有舍入，首次快照以后只能算已观察到的日消耗下界。交互界面 `/usage`在测试版本可读周额度，`grok usage <SESSION_ID>`只查会话 Token／成本。账本脚本仅保存你输入的快照，不会自动查余额或提醒。
4. **网络代理**：直连使用者无需配置。若所在网络需要代理，可选用 [`extras/windows-proxy/`](../extras/windows-proxy/README.md) 的进程级示例，先找到自己客户端的 HTTP(S) 或 Mixed 端口。仓库没有预设 Clash 节点、系统代理或固定端口；`invoke-agy.ps1` 的 `-ProxyUri` 也是可选参数。

无需照抄作者的账户安排、机器目录或全部模型偏好。调整后先在范围清楚、可验收的小任务中试用；有持续价值的观察可按[经验记录](../skills/subagent-manager/references/experience.md)的格式记录，重大规则变化单独审查。不要将认证文件、令牌、账单或包含私人原文的调试日志提交到仓库。
