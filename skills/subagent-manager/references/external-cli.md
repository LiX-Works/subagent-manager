# 外部 CLI 子代理的交接

外部 CLI 与 Codex 原生子代理是两条不同执行路径。先确认可执行入口、当前登录方式、模型与工具可用性；小范围任务通过不证明长期稳定或所有专用工具可用。

给 CLI 的任务应包含目标、已授权材料、边界、来源要求和预期输出。尽量使用独立工作目录与适当时限；长任务不要仅靠提示词要求“只读”，还要利用客户端支持的权限或沙箱设置。程序化调用时检查退出码、输出、工具事件和错误信息，不把模型的自述当成真实调用记录。

需要网络代理时，可在仓库的**可选模块**中查看进程级设置示例；这不是 Skill 的前提。CLI 的认证、账单和账号归使用者自己的环境管理，出错时先有限排查，再交还主代理或报告，不复制凭据、不自动切换付费路径。
