# 模型档位配置示例

这是一组可供改造的个人配置，**不是公共 Skill 的默认最低档位**。只有当前用户明确采用时才按表执行；实际可用模型与思考强度仍以本轮工具 schema 为准。表中暂未加入 GPT-6 Sol/Luna，可在后续版本调整。

| 模型 ID | 示例中的最低档位 | 适合考虑的任务 |
|---|---|---|
| `gpt-5.6-luna` | xhigh | 简单、明确、易验收 |
| `gpt-5.6-terra` | high | 常规至中等复杂分析或代码 |
| `gpt-5.6-sol` | 无额外限制 | 较复杂任务，通常从 medium 及以上考虑 |
| `gpt-6-astra` | 无额外限制 | 较难或重要的判断，通常选择不超过 high 的档位 |

不必先让较便宜的模型失败一次才升级。指定组合时在实际调用参数中传入并核对，不依赖主代理隐式继承；组合不可用则说明限制。成本、准确率和耗时应按任务实测修订这份示例。
